# Problem Statement

We are addressing the "Urban Furniture Accounting System" hackathon problem.
The goal is to build an end-to-end accounting workflow that handles master data, transactions (purchases/sales), invoicing, payments, and double-entry accounting ledgers.

Our key insight is that a standard CRUD app won't win. We must build "Smart Accounting for Urban Furniture", demonstrating a robust accounting engine overlaid with rule-based financial intelligence and high-quality UX that explains the financial impact of every user action.
