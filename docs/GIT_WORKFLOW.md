# Git Workflow

1. Main branch is `main`.
2. As a 2-person team, we will split work between Backend/Accounting Engine (Member 1) and Frontend/UX (Member 2).
3. We will branch off for specific features (e.g., `feat/accounting-engine`, `feat/dashboard-ui`).
4. Commit often, ensuring the "API Contract" is adhered to by both members.
5. All code must pass basic transaction-to-ledger tests before merging into main.
6. Current active feature: `feat/journal-entries-ledger-ui` (Full Ledger navigation & Quiet Luxury double-entry cards).
